Clusterização de Resumos de Artigos Científicos para Extração de Insights Temáticos 

: Aplicar técnicas de Processamento de Linguagem Natural (NLP) e algoritmos de clusterização para identificar e agrupar automaticamente temas predominantes em resumos de artigos científicos. 

Itens Obrigatórios

Exploração e Preparação dos Dados
Realizar a limpeza e normalização dos textos (remoção de stopwords, tokenização, etc.).
Aplicar técnicas de vetorização de texto (como TF-IDF ou embeddings com Word2Vec ou BERT) para transformar os resumos em dados numéricos.
Aplicação de Algoritmos de Clusterização
Experimentar ao menos dois algoritmos de clusterização (por exemplo, K-means e DBSCAN).
Justificar a escolha dos algoritmos e descrever os parâmetros utilizados.
Redução de Dimensionalidade e Visualização
Usar técnicas de redução de dimensionalidade (PCA ou t-SNE) para facilitar a visualização dos clusters.
Visualizar os clusters formados em gráficos de dispersão ou nuvens de palavras, evidenciando os principais temas de cada grupo.
Análise e Interpretação dos Resultados
Avaliar a qualidade dos clusters gerados utilizando métricas de clusterização (ex.: Silhouette Score, Davies-Bouldin Index).
Descrever os temas identificados em cada cluster, discutindo possíveis insights sobre as áreas científicas.
