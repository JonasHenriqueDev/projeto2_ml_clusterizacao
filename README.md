# Clusterização de Resumos de Artigos Científicos para Extração de Insights Temáticos

Aplicar técnicas de Processamento de Linguagem Natural (NLP) e algoritmos de clusterização para identificar e agrupar automaticamente temas predominantes em resumos de artigos científicos.

---

## Itens Obrigatórios

### 1. Exploração e Preparação dos Dados
- **Realizar a limpeza e normalização dos textos:**
  - Remoção de stopwords
  - Tokenização
  - Normalização dos textos
- **Aplicar técnicas de vetorização de texto:**
  - TF-IDF (Term Frequency-Inverse Document Frequency)
  - Embeddings com Word2Vec ou BERT para transformar os resumos em dados numéricos

### 2. Aplicação de Algoritmos de Clusterização
- **Experimentar ao menos dois algoritmos de clusterização:**
  - Exemplo: K-means e DBSCAN
- **Justificar a escolha dos algoritmos e descrever os parâmetros utilizados.**

### 3. Redução de Dimensionalidade e Visualização
- **Usar técnicas de redução de dimensionalidade:**
  - PCA (Principal Component Analysis)
  - t-SNE (t-Distributed Stochastic Neighbor Embedding)
- **Visualizar os clusters formados:**
  - Gráficos de dispersão
  - Nuvens de palavras para evidenciar os principais temas de cada grupo

### 4. Análise e Interpretação dos Resultados
- **Avaliar a qualidade dos clusters gerados utilizando métricas de clusterização:**
  - Silhouette Score
  - Davies-Bouldin Index
- **Descrever os temas identificados em cada cluster:**
  - Discussão de possíveis insights sobre as áreas científicas representadas
